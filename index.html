关于本项目

这是一个学习用「效率小工具箱」，从 Day 2 的一个占位页逐步长成今天的样子。

  • 📐 纯前端：原生 HTML + CSS + JavaScript，零第三方库
  • ☁️ 真实数据：工具列表与今日热点来自云端数据库（第 3 周接入）
  • 🗺️ 四工具：倒计时 / 单位换算 / 密码生成 / 中英翻译

使用说明

所有工具都「打开即用」，无需登录或设置：

  • ⏱️ 倒计时器：填好时分秒 → 开始，时间到会闪烁并响铃
  • 📐 单位换算器：输入数字，选单位，结果实时出来
  • 🔑 密码生成器：选长度和字符集 → 生成 → 一键复制
  • 🌐 中英翻译：输入内容，自动识别方向并逐词翻译
